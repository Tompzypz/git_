git：版本管理仓库

git init：仓库文件初始化
commit：对版本进行正式的提交（git保存文件内此时所有状态的快照）
（可以直接在vscode左边栏进行操作）

三中基本的操作：
discard：放弃还没commit的更改
reset：把仓库强制回退到某个历史状态
revert：生成反向commit抵消某次commit（多人协作的分支上优先使用）

branch建立分支（vscode左下角可以操作，并进行随时切换）
merge操作可以使得分支合并回主干（main/master）
概念head：当前仓库处于哪一次commit上面
detached：分离头指针，可以让整个仓库代码回退到某个分支上面，但此状态下尽量不要修改代码，一般用于查看
（非常实用的功能，不过一般不建议在head指向历史版本的时候进行代码编辑）
（操作：在vscode中，右键点击“Graph”的某个历史版本，然后选择“Checkout Detached”）

Git Areas（分区）概念介绍
Working Directory（工作区）：电脑磁盘上的本地文件夹
Local Repository（本地仓库）：commit以后改动就提交到了本地仓库
Remote Repository（远程仓库）：如GitHub

几种常见操作：
git clone：将远端仓库直接同步到工作区
git push（publish）：将本地仓库直接上传到远程仓库
